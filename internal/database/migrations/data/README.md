# Reference Data Sources

This directory contains static reference datasets embedded into database seeds.

## Datasets

### lebanon_cities.json
- **Source:** United Nations Office for the Coordination of Humanitarian Affairs (UN OCHA) / Humanitarian Data Exchange (HDX) Lebanon administrative boundaries dataset.
- **License / Terms:** Creative Commons Attribution for Intergovernmental Organisations (CC BY-IGO).
- **Attribution:** Sourced from UN OCHA / HDX administrative datasets for Lebanon.

### countries.json
- **Source:** A widely shared public list of country names.
- **License / Terms:** The upstream list states no license.
